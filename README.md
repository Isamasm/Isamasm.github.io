# Isamasm.github.io

Personal portfolio website showcasing my work in system administration, infrastructure, and homelabbing.

## About

I'm a system administrator specializing in Linux, networking, virtualization, and server management. My portfolio features projects ranging from homelab setups to enterprise infrastructure platforms.

## Projects

- **Advanced Proxmox Home Lab** - Production-grade homelab with Pi-hole, Jellyfin, Icecast, Portainer, NAS, and Tailscale
- **Hybrid Infrastructure Management Platform** - Azure-based hybrid cloud with Terraform, Ansible, Zabbix, and GLPI
- **Containerized Web + FTP Infrastructure** - Docker/Kubernetes-based web services with databases and file transfer
- **Advanced Proxmox Cluster** - Multi-node high-availability cluster with Ceph/ZFS storage
- **Private OpenStack Cloud** - Complete OpenStack deployment with Kolla-Ansible automation
