Advanced Proxmox Home Lab with Integrated Services

Production-grade homelab for testing network architectures and containerized services

Objective

Built a personal, production-grade homelab to test and validate network architectures, security systems, and containerized services. This environment serves as a real-world testing ground for enterprise technologies at a smaller scale.

Technologies Used

Proxmox VE Docker Pi-hole Jellyfin Icecast Shoutcast Portainer TrueNAS Nextcloud Tailscale

Implemented Services

Pi-hole

DNS Sinkhole: Deployed as a DNS sinkhole to block ads, trackers, and malicious domains across the entire home network. This significantly improves security and performance by preventing unwanted content from loading on any connected device.

Network-wide Protection: Protects all devices on the network without individual configuration.

Jellyfin Media Server

Self-hosted Media Streaming: Full-featured media streaming platform for movies, TV shows, and music. Supports transcoding for various client devices and user access control.

Multi-user Access: Allows multiple users with personalized libraries and preferences.

Icecast/Shoutcast Radio Station

Audio Broadcasting: Set up an Icecast/Shoutcast server for broadcasting audio content. Features automated playlist management and streaming capabilities.

Custom Content: Enables creation of personalized radio streams with scheduled content.

Portainer

Docker Management: Implemented Portainer CE for centralized Docker container management. Provides GUI-based deployment, monitoring, and logging across all containers.

Simplified Operations: Makes container management accessible without CLI knowledge.

NAS (Network-Attached Storage)

Centralized Storage: Configured TrueNAS/Nextcloud for centralized file storage, automated backups, and secure sharing across all devices on the network.

Data Redundancy: Implements RAID configurations and snapshot capabilities for data protection.

Tailscale

VPN for Remote Access: Deployed Tailscale VPN for secure remote access to the homelab from anywhere. Enables seamless management without exposing services to the public internet.

Zero Configuration: Uses WireGuard under the hood for fast, secure connections without complex setup.

Impact & Skills Demonstrated

  • Virtualization Expertise: Proficient in Proxmox VE for creating and managing virtual machines and containers
  • Containerization: Deep understanding of Docker and container orchestration
  • Network Security: Experience with DNS filtering, VPNs, and secure network configurations
  • Self-hosted Services: Ability to deploy and manage various self-hosted applications
  • Remote Management: Secure remote access solutions without compromising security
  • Storage Solutions: Knowledge of NAS configurations and data management
  • Network Architecture: Understanding of how different services interact within a network

Architecture Overview

The homelab runs on Proxmox VE as the hypervisor, with various services deployed as either virtual machines or Docker containers. Network segmentation is implemented to separate different service types, and Tailscale provides secure external access. Storage is centralized through the NAS solution, with regular backups to prevent data loss.
