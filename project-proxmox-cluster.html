Advanced Proxmox Cluster for High Availability

Multi-node Proxmox cluster with distributed storage and fault tolerance

Objective

Extended my Home Lab to create a high-availability Proxmox cluster for testing advanced network architectures and preparing for future projects. This cluster provides a resilient foundation for experimenting with enterprise-grade technologies.

Technologies Used

Proxmox VE Ceph ZFS HA K3s Tailscale

Implemented Components

Multi-Node Cluster

Distributed Infrastructure: Deployed Proxmox VE across multiple physical nodes for redundancy and high availability. This ensures that the cluster remains operational even if individual nodes fail.

Resource Pooling: Aggregates compute and storage resources from all nodes into a single pool.

Shared Storage (Ceph/ZFS)

Distributed Storage: Configured Ceph or ZFS for distributed and replicated storage. This enables live migration of virtual machines (VMs) between nodes without downtime.

Data Redundancy: Implements replication to protect against data loss from hardware failures.

High Availability (HA)

Automatic Failover: Implemented Proxmox HA to automatically restart VMs on other nodes in case of hardware failure. This minimizes downtime and ensures service continuity.

Health Monitoring: Continuous monitoring of node health and automatic recovery actions.

K3s Preparation

Kubernetes Foundation: Set up the infrastructure to support a future K3s (lightweight Kubernetes) cluster for testing containerized applications at scale.

Container Orchestration: Prepares the environment for running Kubernetes workloads alongside traditional VMs.

Network Testing

Architecture Validation: Used the cluster to validate complex network architectures, including VLANs, routing policies, and security configurations.

Performance Testing: Tests network performance and latency across different configurations.

Tailscale Integration

Secure Remote Management: Connected the cluster to Tailscale for secure remote management and access from external networks without exposing services to the public internet.

Zero Trust Networking: Implements modern security principles for remote access.

Cluster Architecture

The cluster consists of multiple Proxmox nodes connected through a high-speed network. Ceph or ZFS provides shared storage across all nodes, enabling VM live migration. The HA system monitors all nodes and automatically redistributes VMs if a node fails. Tailscale provides secure remote access to the management interface and VM consoles.

The infrastructure is designed to support both traditional virtual machines and modern containerized workloads through K3s, making it a versatile platform for testing various deployment scenarios.

  • Cluster Management: Ability to design and manage multi-node Proxmox clusters
  • High Availability: Expertise in configuring and managing HA systems for fault tolerance
  • Distributed Storage: Knowledge of Ceph and ZFS for shared, replicated storage
  • Virtualization: Deep understanding of Proxmox VE and virtual machine management
  • Network Architecture: Ability to design and validate complex network configurations
  • Remote Management: Experience with secure remote access solutions like Tailscale
  • Kubernetes Preparation: Understanding of infrastructure requirements for Kubernetes deployments
  • Fault Tolerance: Knowledge of designing systems that continue operating despite failures

Use Cases

This cluster serves multiple purposes:

  • Testing Environment: Safe environment for testing new technologies and configurations
  • Learning Platform: Hands-on experience with enterprise-grade clustering and HA technologies
  • Development Platform: Hosts development and staging environments for various projects
  • Research & Experimentation: Allows exploration of different infrastructure configurations and their impacts
  • Proof of Concept: Demonstrates capabilities for potential production deployments
