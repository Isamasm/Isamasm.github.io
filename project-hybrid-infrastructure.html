Hybrid Infrastructure Management Platform

Enterprise hybrid cloud infrastructure with monitoring and automation

Objective

Designed and deployed a hybrid (on-premises + Azure cloud) infrastructure management platform during my internship at Holcim Agadir. This platform integrates cloud resources with on-premises infrastructure to create a unified, manageable environment.

Technologies Used

Microsoft Azure Docker Terraform Ansible Zabbix Grafana GLPI Windows Server Active Directory Azure Entra ID

Implemented Components

Azure Integration

Cloud Services: Utilized Microsoft Azure for cloud resources, including IaaS/PaaS services, identity management, and Role-Based Access Control (RBAC).

Hybrid Connectivity: Established secure connections between on-premises and cloud environments.

Docker Containers

Containerization: Containerized key services for portability, scalability, and isolation. This approach enables consistent deployment across different environments.

Service Isolation: Each service runs in its own container with defined resource limits.

Terraform (Infrastructure as Code)

Automated Provisioning: Used Infrastructure as Code to automate the provisioning of cloud and on-premises resources, ensuring consistency and reproducibility.

Version Control: Infrastructure definitions are versioned and managed like application code.

Ansible Automation

Configuration Management: Automated configuration management for servers, services, and applications, significantly reducing manual setup time.

Idempotent Operations: Configuration changes are applied consistently regardless of current state.

Zabbix + Grafana Monitoring

Real-time Monitoring: Implemented Zabbix for comprehensive monitoring of servers, networks, and applications. Grafana provides visualization and alerting capabilities.

Dashboard Visualization: Custom dashboards for tracking performance metrics and system health.

GLPI Asset Management

IT Asset Tracking: Deployed GLPI for IT asset management, ticketing, and incident tracking, streamlining support workflows.

Lifecycle Management: Tracks hardware and software assets throughout their lifecycle.

Windows Server + Active Directory

Directory Services: Configured Windows Server with Active Directory for user management, group policies (GPOs), and centralized authentication.

Domain Management: Manages user accounts, permissions, and policies across the organization.

Azure Entra ID (formerly Azure AD)

Hybrid Identity: Enabled hybrid identity synchronization between on-premises Active Directory and Azure cloud, ensuring seamless access across environments.

Single Sign-On: Provides unified authentication experience for users across cloud and on-premises.

Impact & Skills Demonstrated

  • Hybrid Cloud Architecture: Ability to design and manage infrastructure spanning both cloud and on-premises
  • Infrastructure as Code: Proficiency with Terraform for automated infrastructure provisioning
  • Configuration Management: Expertise in Ansible for automated server and service configuration
  • Monitoring & Observability: Comprehensive monitoring setup with Zabbix and Grafana
  • Identity Management: Experience with Active Directory and Azure Entra ID for user authentication
  • Asset Management: Knowledge of IT asset tracking and lifecycle management with GLPI
  • Containerization: Deep understanding of Docker and container-based deployments
  • Enterprise Integration: Ability to integrate disparate systems into a cohesive platform

Business Value

This platform significantly improved operational efficiency at Holcim Agadir by:

  • Reducing manual deployment and configuration time through automation
  • Improving system reliability through comprehensive monitoring and alerting
  • Enabling seamless access to resources from both on-premises and cloud environments
  • Centralizing IT asset management and support ticketing
  • Providing better visibility into infrastructure health and performance
